# WebTech assignment
A mini web development project built with HTML, CSS, and JavaScript, designed for learning and practicing front-end web development.
The main highlight: client-side form validation for better user experience.

## Features
  •	Multi-page website:
      o	index.html → Home page
      o	register.html → Registration form with real-time validation
      o	donate.html → Donation form with validation checks
      o	programs.html → Programs/info page
  •	Form validation using JavaScript (form-validation.js)
  •	Clean and simple CSS styling (webstyle.css)
  •	Interactive feedback for users (error messages for invalid input)

## Tech Used
  •	HTML5 – Structure of pages
  •	CSS3 – Styling and layout
  •	JavaScript (ES6) – Form validation logic

## Notes / Learning Highlights
  •	Shows basic web development workflow for students
  •	Demonstrates form validation (required fields, email format, password checks, etc.)
  •	Good example of connecting JS with HTML forms
  •	Clean, commented code for easy understanding and modification
